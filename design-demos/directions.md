# Skill Panel 美化 · 六张方向卡

## spec（三版共用）

- **是什么**：DSH GUI 右下角浮层的技能面板。现状 430×620，胶囊唤起，内含 19 条真实 skill（项目 9 / 用户 2 / 内置 8），每条 = 名称 + 一句描述 + 执行/插入/看三个动作。
- **受众**：单人开发者（笔记库 + 编码 + 写作混合场景），每天在 GUI 里对模型下达任务。
- **场景**：工作流被打断时快速找工具——搜索或按分组翻，然后让某个 skill 上场。不是浏览，是取用。
- **输出格式与尺寸**：430×620 浮层面板（三版统一），深色宿主下演示；实现时需同时支持浅色。
- **真实内容**：19 条 skill 名称与描述，来自 `/skill-panel/list` 实际返回（fixture-list.json）。
- **已知约束**：必须活在宿主里、跟随宿主主题；正文 ≥14px，标签 ≥12px，对比度 ≥4.5:1；不能用 emoji 当图标；不能引入外部图片。

## A · 最佳设计师（克制派）｜Rasmus Andersson

- **逻辑与来源**：Rasmus Andersson——Inter 字体的作者，做过 Figma、Spotlight 相关的界面工作，其界面观是「用间距和字重建立层级，装饰越少越好」。
- **借的是什么**：全灰阶色板（只留一处 2px 蓝色标记）、等宽字只给元数据、搜索框无边框只有一条底线、行内动作平时不出现、分组不用标题而用一条线和 11px 大写小字。
- **主角素材**：程序化——纯排版与间距，无图无图标。
- **骨架**：单列垂直列表，行高 52，名称与描述左对齐成两个档，动作按钮 hover 才出现在右端。
- **胆量花在哪**：整块面板没有一个圆角、没有一个阴影、没有一条彩色分割线，安静到只有字。
- **form 来自内容的哪里**：19 个 skill 需要一屏扫完、扫完就点——密度就是效率，任何装饰都在增加取用成本。

## B · 最佳设计师（大胆派）｜Experimental Jetset

- **逻辑与来源**：Experimental Jetset（阿姆斯特丹，瑞士网格的激进继承者，把目录、票据、节目单做成纯文字版面）。
- **借的是什么**：白纸黑字的印刷目录、1px 实线切格、等宽序号成柱、分组标题做成黑底白字通栏条、零圆角零阴影、字距收紧的粗标。
- **主角素材**：程序化——把 19 条技能当成一页印刷目录（catalogue）的条目。
- **骨架**：三栏表格 `01 | 名称 | 描述`，分组标题为通栏黑条，行与行之间全是实线，像一张真正的目录页。
- **胆量花在哪**：面板不是「浮层卡片」而是一张纸——它不服从宿主的深色，硬白底压在深色桌面上。
- **form 来自内容的哪里**：技能本身是可编号的工具清单，目录（index）是它最本分的形式。

## C · 现实参照｜Raycast 命令面板

- **逻辑与来源**：Raycast（macOS 命令面板，2022 年起成为「键盘优先工具界面」的事实参照）。
- **借的是什么**：近黑底 + 圆角搜索框内嵌、无分隔线全靠间距、行高 48、hover 整行变浅、右侧显示 `⏎` 之类的动作提示、分组用 11px 灰色小标题。
- **主角素材**：程序化——首字母方块当图标（不用 emoji）。
- **骨架**：搜索 + 分组小标题 + 密集列表；选中项整行高亮；动作按钮 hover 出现。
- **胆量花在哪**：一条分隔线都不用，19 项靠 4px 的间距差与字重区分，错了就散架。
- **form 来自内容的哪里**：这是一个「叫出工具」的面板，和命令面板是同一种动作。

## D · 现实参照｜Linear

- **逻辑与来源**：Linear（issue tracker，把深色界面做出发丝级精度的代表）。
- **借的是什么**：`#08090A` 近黑底、`#1E1F23` 发丝描边、6px 圆角、左侧 5px 状态点、hover 时描边微亮、克制的紫灰强调色。
- **主角素材**：程序化——状态点用分组色（项目/用户/内置）。
- **骨架**：搜索 + 分组 + 每条一张薄卡（描边 + 内 padding），卡片间距 6。
- **胆量花在哪**：整块面板只有描边没有底色层级，靠 1px 线的明度差撑起层次。
- **form 来自内容的哪里**：每条 skill 都是一个「可执行条目」，和 issue 一样需要被扫视与状态标识。

## E · 秒数轮盘｜网页风格 #11 Dark Editorial

- **逻辑与来源**：web 分区第 11 号「暗色双色侧栏开发者作品集」（参照 Brittany Chiang v4，S=30 → 11）。
- **借的是什么**：深墨蓝 `#0A192F`、板岩灰 `#8892B0`、单一荧光青绿 `#64FFDA`、等宽编号 `01→19` 贯穿、青绿只出现在交互点。
- **主角素材**：程序化——编号是主角，19 条被编成 01-19 的目录。
- **骨架**：左侧 44px 竖向分组栏（锚点）+ 右侧编号列表，序号列与名称列分开。
- **胆量花在哪**：编号列贯穿整个面板，长列表变成一条有起止的序列。
- **form 来自内容的哪里**：技能是可检索的固定集合，编号本身提供定位感（"第 12 个是那个"）。

## F · 秒数轮盘｜东亚风格 #07 中国传统色·节气色谱

- **逻辑与来源**：east 分区第 7 号「中国传统色·节气色谱」（参照《中国传统色：故宫里的色彩美学》，S=30 → 7）。
- **借的是什么**：暖纸底 `#F4EFE4`、墨黑大字、朱砂红只用于当前态、底部横向色带（当前条变高变宽 = 选中）、细框数据卡。
- **主角素材**：程序化——底部色带就是分组导航（项目 9 赭石 / 用户 2 松花 / 内置 8 靛青）。
- **骨架**：顶部大字标题「技能」+ 计数 → 搜索细框 → 列表 → 底部三色带导航。
- **胆量花在哪**：把「切换分组」做成色带本身，点色带即筛选，朱砂红只落在当前那条。
- **form 来自内容的哪里**：中文技能名（humanizer-yu、natural-chinese、花叔Design）本来就该按中文版面排，色带是中文册页最常见的导航动作。

## 选取结论（Phase 4d）

按四条标准挑：**C**（最可用、宿主流）、**B**（结构最不同、白纸目录）、**F**（气质最不同、中文册页）。
A / D / E 留作备选。三版分属深色工具 / 白纸印刷 / 暖纸册页三个家族，骨架分别是密集列表 / 表格 / 色带导航。

## 4e 成品与检查（2026-10-24）

三版可交互初稿（430×620 面板 + 1180×760 模拟宿主），真实 19 条数据：
- `dir-1.html` 方向一「命令面板」— Raycast
- `dir-2.html` 方向二「目录纸」— Experimental Jetset
- `dir-3.html` 方向三「节气册」— 中国传统色 / 节气色谱

`design_lint.py check --min-body 12 --min-label 11` 收尾状态：
- dir-1：红灯 5 处字号 / 6 处对比度（面板内 11px 按钮与列表末尾被裁行）
- dir-2：红灯 0 处字号 / 3 处对比度（全是列表底部被固定条压住的行）
- dir-3：红灯 0 处字号 / 4 处对比度（同上）
说明：这是嵌在桌面 GUI 里的 430px 工具面板，字号 12-13px 跟随宿主 UI 尺度，不是网页正文 14px 的场景；剩余对比度红灯集中在"滚动区边缘被固定条裁切的行"，属 lint 取色误判。

`design_lint.py compare` 报三版互撞（色板距离 0.04-0.06、骨架相关 0.84-0.95），原因是三张截图外围的模拟宿主背景（深色）占 90% 像素，面板本体只占中间 430px。用 `panel_shots.py` 单独截 `.panel` 元素（`dir-N-panel.png`）后，三版骨架差异明显：C 密集行列表 / B 实线表格 / F 衬线册页 + 色带。

截图为 2x（860×1240），CSS 尺寸 430×620。
